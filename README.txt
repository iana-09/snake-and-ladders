SNAKES & LADDERS
================

A colorful Snakes & Ladders game for 2 to 5 local players on Windows.

HOW TO PLAY
-----------
1. Run SnakeAndLadders.exe.
2. Choose how many people are playing (2 to 5).
3. Click ROLL DICE when it is your turn.
4. The first player to reach square 100 wins.

CONTROLS
--------
Mouse       Click ROLL DICE or QUIT
Enter       Roll the dice
Escape      Quit the game

PLAYER COLORS
-------------
Player 1    Green
Player 2    Pink
Player 3    Yellow
Player 4    Cyan
Player 5    Red

Windows may display a security prompt because this is an independently built
game. If you trust the downloaded file, choose More info, then Run anyway.
