SNAKES & LADDERS
================

A colorful local multiplayer version of the classic Snakes & Ladders board game
for Windows. Choose 2 to 5 players, roll the dice, climb ladders, and avoid
the friendly cartoon snakes. The first player to reach square 100 wins.

FEATURES
--------
- Supports 2 to 5 local players
- Player-count selection screen before the game starts
- Colorful 100-square board with cartoon snakes and ladders
- Five distinct player pawns
- Animated movement and dice rolls
- Extra turn when a player rolls a six
- Exact roll required to reach square 100

HOW TO PLAY
-----------
1. Run SnakeAndLadders.exe.
2. Choose how many people are playing (2 to 5).
3. Press START GAME (or press Enter).
4. Click ROLL DICE when it is your turn.
5. The first player to reach square 100 wins.

CONTROLS
--------
Mouse       Select players, start, roll, or quit
2-5         Select the number of players
Enter       Start the game or roll the dice
Escape      Quit the game

PLAYER COLORS
-------------
Player 1    Green
Player 2    Pink
Player 3    Yellow
Player 4    Cyan
Player 5    Red

DOWNLOAD & INSTALL
-------------------
1. Download the Windows ZIP package.
2. Extract the ZIP file to a folder.
3. Open the extracted folder.
4. Double-click SnakeAndLadders.exe.

No installation is required. The game runs directly from the extracted folder.

If Windows displays a security warning, select More info, then Run anyway if
you trust the downloaded file.

Windows may display a security prompt because this is an independently built
game. If you trust the downloaded file, choose More info, then Run anyway.
